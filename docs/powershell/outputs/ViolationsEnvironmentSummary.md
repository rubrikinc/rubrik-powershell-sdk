### ViolationsEnvironmentSummary
Violations summary of an environment.

- platformEnv: PlatformCategory
  - Platform env of the violation.
- totalViolationCount: System.Int32
  - Total number of violations.
- newViolationsCount: System.Int32
  - Number of new violations.
- criticalSeverityViolationCount: System.Int32
  - Number of critical severity violations.
- newCriticalSeverityViolationCount: System.Int32
  - Number of new critical severity violations.
- highSeverityViolationCount: System.Int32
  - Number of high severity violations.
- newHighSeverityViolationCount: System.Int32
  - Number of new high severity violations.
- mediumSeverityViolationCount: System.Int32
  - Number of medium severity violations.
- newMediumSeverityViolationCount: System.Int32
  - Number of new medium severity violations.
- lowSeverityViolationCount: System.Int32
  - Number of low severity violations.
- newLowSeverityViolationCount: System.Int32
  - Number of new low severity violations.
