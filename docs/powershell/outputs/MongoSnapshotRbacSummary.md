### MongoSnapshotRbacSummary
Supported in v9.6+
Summary of the role-based access control (RBAC) data captured in a snapshot of a MongoDB admin database. Lists the user accounts in the snapshot and the roles granted to each account.

- users: list of MongoSnapshotRbacUsers
  - Required. Supported in v9.6+
User accounts captured in the snapshot of the admin database.
