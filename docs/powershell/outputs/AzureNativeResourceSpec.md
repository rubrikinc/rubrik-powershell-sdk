### AzureNativeResourceSpec
Azure virtual machine resource spec.

- snappableId: System.String
  - ID of Azure virtual machine.
- snapshotId: System.String
  - ID of snapshot.
- snappableName: System.String
  - Name of Azure virtual machine.
- isArchived: System.Boolean
  - Specifies whether resource specification is archived.
- recoveryPointOpt: System.Int64
  - Recovery point of the Azure virtual machine.
- sizeType: System.String
  - Size type of Azure virtual machine.
- availabilityZone: System.String
  - Availability zone associated with the Azure virtual machine.
- isAcceleratedNetworkingEnabled: System.Boolean
  - Specifies whether accelerated networking is enabled on the Azure virtual machine.
