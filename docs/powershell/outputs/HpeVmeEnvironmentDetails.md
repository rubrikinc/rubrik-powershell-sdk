### HpeVmeEnvironmentDetails
Details of an HPE Virtual Machine Essentials environment.

- hpeVmeManagerId: System.String
  - HPE Virtual Machine Essentials manager ID.
- hpeVmeHostId: System.String
  - HPE Virtual Machine Essentials host ID.
- ipAddresses: list of System.Strings
  - List of IP addresses.
- versions: list of System.Strings
  - List of versions.
- hostName: System.String
  - Hostname of the HPE Virtual Machine Essentials manager.
- username: System.String
  - Username for the HPE Virtual Machine Essentials manager.
- connectionStatus: RefreshableObjectConnectionStatus
  - Connection status of the HPE Virtual Machine Essentials manager.
- isRefreshed: System.Boolean
  - Whether the HPE Virtual Machine Essentials manager has been refreshed.
- lastRefreshTime: DateTime
  - Last refresh time of the HPE Virtual Machine Essentials manager.
