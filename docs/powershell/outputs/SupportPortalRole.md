### SupportPortalRole
Rubrik Support portal role.

- canCreateCases: System.Boolean
  - Whether a user is allowed to create a case.
- hasEscalateCasesPermission: System.Boolean
  - Whether a user is allowed to request escalation on a case.
- hasUpdateCaseStatusPermission: System.Boolean
  - Whether a user is allowed to open or close a case.
- hasUploadFilesPermission: System.Boolean
  - Whether a user is allowed to upload file attachments to a case.
