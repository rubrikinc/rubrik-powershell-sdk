### AdAttributeSchemaMetadata
On-prem AD attribute schema-specific metadata.

- attrId: System.String
  - Specifies the attribute ID.
- systemOnly: System.Boolean
  - Specifies if the attribute is system only.
- syntax: System.String
  - Specifies the syntax of the attribute.
- adminDisplayName: System.String
  - Specifies the admin display name of the attribute.
- ldapName: System.String
  - Specifies the LDAP name of the attribute.
- systemFlags: System.String
  - Specifies the system flags of the attribute.
- omSyntax: System.String
  - Specifies the OM syntax of the attribute.
