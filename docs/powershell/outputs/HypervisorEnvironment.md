### HypervisorEnvironment
Details of a Hypervisor environment.

- fid: System.String
  - FID of the Hypervisor environment.
- hypervisorEnvironmentId: System.String
  - ID of the Hypervisor environment.
- name: System.String
  - Name of the Hypervisor environment.
- hypervisorDetails: HypervisorEnvironmentDetails
  - Details of the Hypervisor environment.
