### GroupNode
GroupNode represents metadata for a group in app access context.

- groupId: System.String
  - ID of the group.
- groupName: System.String
  - Display name of the group.
- memberCount: System.Int32
  - Number of direct members in the group.
- principalType: PrincipalRiskySummaryPrincipalType
  - Principal type of the group.
- nativeType: NativeType
  - Native type of the group.
