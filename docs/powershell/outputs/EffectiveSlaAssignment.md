### EffectiveSlaAssignment
Effective SLA is important for services that simply need to know whether
an object is protected, and if so, with which SLA.

- isUnprotected: System.Boolean
  - Object is not protected.
- effectiveSlaId: System.String
  - ID of the effective SLA on the object.
- effectiveRetentionSlaId: System.String
  - ID of the effective retention SLA on the object.
