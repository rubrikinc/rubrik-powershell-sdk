### GetPrincipalSummaryReply
GetPrincipalSummaryReply contains the summary of the principal.

- summary: PrincipalSummary
  - Principal summary.
- privilegedMembersCount: Count
  - Privileged members count of the principal.
- privilegedMembersofCount: Count
  - Privileged members-of count of the principal.
- privilegedRolesCount: Count
  - Privileged roles count of the principal.
- secretsCount: System.Int32
  - Number of secrets assigned to the principal.
- privilegedApiPermissionsCount: Count
  - Count of privileged API permissions granted to the principal.
