### CloudDirectCopyScheduleAssignmentList
ListCopyScheduleAssignmentReply is the response for ListCloudDirectCopyScheduleAssignments.

- assignments: list of CloudDirectCopyScheduleAssignmentItems
  - Assignments are the share-to-schedule links matching the request's
filters.
- nextPageCursor: System.String
  - Next page cursor is the continuation token for the following page, or
empty when this is the last page.
