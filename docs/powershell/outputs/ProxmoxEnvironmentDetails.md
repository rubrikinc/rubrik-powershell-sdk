### ProxmoxEnvironmentDetails
Details of a Proxmox environment.

- proxmoxEnvironmentId: System.String
  - Proxmox environment ID.
- proxmoxClusterId: System.String
  - Proxmox cluster ID.
- proxmoxNodeId: System.String
  - Proxmox node ID.
- ipAddresses: list of System.Strings
  - List of IP addresses.
- versions: list of System.Strings
  - List of versions.
