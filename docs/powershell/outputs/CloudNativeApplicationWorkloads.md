### CloudNativeApplicationWorkloads
CloudNativeApplicationWorkloads groups workload
IDs by their cloud native object type.

- objectType: CloudNativeObjectType
  - Cloud native object type (e.g., AWS_EC2_INSTANCE,
AWS_RDS_INSTANCE).
- workloadIds: list of System.Strings
  - List of workload IDs of this type.
- count: System.Int32
  - Number of workload IDs.
