### MongoSnapshotRbacRoleAssignment
Supported in v9.6+
A role granted to a MongoDB user account, along with the database in which the role is defined.

- db: System.String
  - Required. Supported in v9.6+
Name of the database in which the role is defined.
- role: System.String
  - Required. Supported in v9.6+
Name of the role granted to the user account.
