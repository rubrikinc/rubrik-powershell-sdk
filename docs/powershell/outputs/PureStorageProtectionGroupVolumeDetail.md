### PureStorageProtectionGroupVolumeDetail
Volume entry showing the current exclusion status for a Pure Storage protection group.

- volumeId: System.String
  - Supported in v9.6+
ID of the Pure Storage volume.
- protectionGroupId: System.String
  - Supported in v9.6+
ID of the Pure Storage protection group.
- isExcludedFromSnapshots: System.Boolean
  - Supported in v9.6+
Whether the volume is excluded from snapshot processing for this protection group.
