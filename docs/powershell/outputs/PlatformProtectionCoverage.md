### PlatformProtectionCoverage
Protection coverage for platform.

- platformCategory: PlatformCategory
  - Platform category.
- protectedObjectsCount: System.Int32
  - Count of objects protected.
- newProtectedObjectsCount: System.Int32
  - Count of new objects protected.
- supportedObjectsCount: System.Int32
  - Count of objects supported.
- protectionPercentCoverage: System.Single
  - Protection percent coverage.
- newProtectionPercentCoverage: System.Single
  - Change in protection percent coverage.
- violatedSensitiveObjects: System.Int32
  - Violated sensitive objects count.
- newViolatedSensitiveObjects: System.Int32
  - New violated sensitive objects count.
