### O365TodoTaskFolder
A task folder (To Do list).

- name: System.String
  - The display name for this task folder.
- snapshotId: System.String
  - The snapshot ID of this version of the task folder.
- snapshotTime: DateTime
  - The snapshot time of this version of the task folder.
- snapshotNum: System.Int32
  - The snapshot number of this version of the task folder.
- id: System.String
  - The ID of the Microsoft 365 Exchange object.
- parentFolderId: System.String
  - The parent folder ID of the object (ROOT indicates root folder).
