### AdAttributeClassSchemaMetadata
On-prem AD attribute class schema-specific metadata.

- governSid: System.String
  - Specifies the governing SID of the attribute class.
- systemOnly: System.Boolean
  - Specifies if the attribute class is system only.
- syntax: System.String
  - Specifies the syntax of the attribute class.
- adminDisplayName: System.String
  - Specifies the admin display name of the attribute class.
- ldapName: System.String
  - Specifies the LDAP name of the attribute class.
- subClassOf: System.String
  - Specifies the subclass of the attribute class.
- omSyntax: System.String
  - Specifies the OM syntax of the attribute class.
