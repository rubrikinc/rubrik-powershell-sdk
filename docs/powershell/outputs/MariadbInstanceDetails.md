### MariadbInstanceDetails
MariaDB instance user details.

- systemUserName: System.String
  - The MariaDB host system user name.
- mariadbUserName: System.String
  - The MariaDB instance username.
- bindIpAddress: System.String
  - The MariaDB instance bind IP address.
- socketFile: System.String
  - The MariaDB instance socket file path.
- sslConfig: MariadbInstanceSslConfig
  - The MariaDB instance SSL configuration.
- authenticationType: MariadbInstanceAuthenticationType
  - The MariaDB instance authentication type.
