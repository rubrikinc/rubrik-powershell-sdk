### MariadbInstanceAdvancedConfig
Advanced configuration for the MariaDB instance.

- mariadbClientBinaryPath: System.String
  - Path to the MariaDB client binary (mariadb). Empty when unset.
- mariadbBackupBinaryPath: System.String
  - Path to the MariaDB-Backup binary (mariadb-backup). Empty when unset.
- mariadbBinlogBinaryPath: System.String
  - Path to the MariaDB-BinLog binary (mariadb-binlog). Empty when unset.
