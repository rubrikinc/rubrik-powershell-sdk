### HypervisorVirtualMachine
Details of a Hypervisor virtual machine.

- fid: System.String
  - FID of the Hypervisor virtual machine.
- hypervisorVmId: System.String
  - ID of the Hypervisor virtual machine.
- name: System.String
  - Name of the Hypervisor virtual machine.
- primaryClusterUuid: System.String
  - Primary cluster UUID.
- hypervisorVmDetails: HypervisorVirtualMachineDetails
  - Details of the Hypervisor virtual machine.
- effectiveSlaDomain: HypervisorSlaDomainInfo
  - Effective SLA Domain of a Hypervisor virtual machine.
- slaAssignment: SlaAssignmentType
  - SLA Domain assignment type of a Hypervisor virtual machine.
