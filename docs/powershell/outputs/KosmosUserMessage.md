### KosmosUserMessage
Kosmos User Message object.
+kosmos:model:max-size=600

- severity: UserMessageSeverity
  - The severity level of this user message.
- messageCode: System.String
  - A machine-readable code identifying the type of message.
- cause: System.String
  - A human-readable description of the root cause.
- remedy: System.String
  - A human-readable suggestion for resolving the issue.
