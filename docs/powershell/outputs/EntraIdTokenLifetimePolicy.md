### EntraIdTokenLifetimePolicy
Represents a token lifetime policy.

- id: System.String
  - ID of the token lifetime policy.
- displayName: System.String
  - Display name of the token lifetime policy.
- isOrganizationDefault: System.Boolean
  - Whether the policy is the default for the organization.
- accessTokenLifetime: System.String
  - Lifetime of the access token.
