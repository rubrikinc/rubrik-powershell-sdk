### DocumentTypeDetails
Represents the details of a document type.

- id: System.String
  - Represents the ID of the document type.
- name: System.String
  - Represents the title of the document type.
- risk: RiskLevelType
  - Represents the risk or sensitivity level of the document type.
- totalHits: System.Int64
  - Represents the total hits for the document type.
- policies: list of ClassificationPolicySummarys
  - Represents the list of policies associated with the document type.
- isActive: System.Boolean
  - Represents whether the document type is active.
