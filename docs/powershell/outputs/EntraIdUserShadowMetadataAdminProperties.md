### EntraIdUserShadowMetadataAdminProperties
Information of shadow admins of the Entra ID User.

- groupId: System.String
  - Object ID of the group that the user is a member of.
- groupName: System.String
  - Display name of the group that the user is a member of.
- roleNames: list of System.Strings
  - List of role names vulnerable to shadow admin.
