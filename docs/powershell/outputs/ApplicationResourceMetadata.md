### ApplicationResourceMetadata
Resource metadata common to all resource types.

- cloudNativeAccountId: System.String
  - Cloud native account ID.
- nativeUri: System.String
  - Native URI from the cloud.
- nativeName: System.String
  - Native name (resource name from cloud provider).
- region: CloudRegion
  - Cloud region where the resource is located.
- tags: ResourceTag
  - Tags associated with the resource.
