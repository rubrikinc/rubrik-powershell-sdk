### DisplayableValueFloat
A floating-point displayable value.

- value: System.Single
  - The floating-point value; unset when there is no value.
- displayValue: System.String
  - The value rendered for display in the UI.
- reportHeader: System.String
  - The value rendered in the report header.
- serializedValue: System.String
  - The value in its serialized string form.
