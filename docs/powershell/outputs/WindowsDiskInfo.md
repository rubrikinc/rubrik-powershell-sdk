### WindowsDiskInfo
Information about a physical disk on the domain controller.

- diskNumber: System.Int32
  - Disk number.
- size: System.Int64
  - Size of the disk in bytes.
- partitionStyle: System.String
  - Partition style of the disk.
- controllerNameOpt: System.String
  - Name of the disk controller.
- controllerHardwareIdOpt: System.String
  - Hardware ID of the disk controller.
- diskTypeOpt: System.String
  - Type of the disk (e.g., SSD, HDD).
