### GcpKmsCryptoKey
A fully qualified GCP KMS crypto key.

- key: System.String
  - Name of the KMS crypto key in the keyring.
- keyRing: System.String
  - Name of the KMS crypto key ring in the location.
- location: GcpKmsLocation
  - KMS crypto key location.
- projectNativeId: System.String
  - GCP project native ID.
