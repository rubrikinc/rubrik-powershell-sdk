### AdComputerMetadata
On-prem AD computer specific metadata.

- location: System.String
  - Specifies the location of the computer.
- dnsName: System.String
  - Specifies the DNS name of the computer.
- osVersion: System.String
  - Specifies the OS version of the computer.
- os: System.String
  - Specifies the OS of the computer.
