### IdpMetadata
Metadata describing an IdP resource involved in a policy violation.

- domainUniqueId: System.String
  - Domain UniqueID.
- domainName: System.String
  - Domain name.
- idpType: IdpType
  - IdP type.
- rootDomainId: System.String
  - Root domain ID.
- rootDomainName: System.String
  - Root domain name.
