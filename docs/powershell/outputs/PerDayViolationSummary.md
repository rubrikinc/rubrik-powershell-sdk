### PerDayViolationSummary
Summary of violations created and remediated on a single day.

- summaryTimestamp: DateTime
  - Date timestamp of the summary.
- numViolationsCreated: System.Int32
  - Number of violations created in the day.
- numCriticalViolationsCreated: System.Int32
  - Number of critical violations created in the day.
- numHighViolationsCreated: System.Int32
  - Number of high violations created in the day.
- numMediumViolationsCreated: System.Int32
  - Number of medium violations created in the day.
- numLowViolationsCreated: System.Int32
  - Number of low violations created in the day.
- numViolationsRemediated: System.Int32
  - Number of violations resolved in the day.
- numCriticalViolationsRemediated: System.Int32
  - Number of critical violations resolved in the day.
- numHighViolationsRemediated: System.Int32
  - Number of high violations resolved in the day.
- numMediumViolationsRemediated: System.Int32
  - Number of medium violations resolved in the day.
- numLowViolationsRemediated: System.Int32
  - Number of low violations resolved in the day.
