### M365Domain
A domain on an M365 subscription, selectable as a cross-tenant recovery
target.

- id: System.String
  - Stable identifier for the domain. Microsoft Graph uses the
fully-qualified domain name as the domain's id, so this carries the same
value as `name`.
- name: System.String
  - Fully-qualified domain name, e.g. "contoso.onmicrosoft.com".
