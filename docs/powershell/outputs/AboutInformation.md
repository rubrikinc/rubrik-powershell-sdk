### AboutInformation
Additional information about a vCenter object, such as name, version,
OS type, and API type. Only available on clusters 5.1+.

- version: System.String
  - Version of the vCenter.
- name: System.String
  - Name of the vCenter.
- apiType: System.String
  - API type of the vCenter.
- osType: System.String
  - OS type of the vCenter.
