### AwsNativeEc2InstanceResourceSpec
AWS EC2 instance resource spec.

- snappableId: System.String
  - ID of AWS EC2 instance.
- snapshotId: System.String
  - ID of snapshot.
- snappableName: System.String
  - Name of AWS EC2 instance.
- isArchived: System.Boolean
  - Specifies whether resource specification is archived.
- instanceType: System.String
  - Instance type of AWS EC2 instance.
- region: System.String
  - Region of AWS EC2 instance.
- recoveryPointOpt: System.Int64
  - Recovery point of the AWS EC2 instance.
