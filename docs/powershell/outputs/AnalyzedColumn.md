### AnalyzedColumn
AnalyzedColumn contains column name and associated data type results.

- columnName: System.String
  - Name of the column that is detected.
- columnDatatypeResults: list of DataTypeResults
  - Data type results for columns.
- columnResults: list of AnalyzedColumns
  - Nested column results.
- columnType: SchemaFieldType
  - Type of column.
