### RvcDeploymentToolLink
Response for the request to get download links for the Rubrik Virtual Cluster Deployment Tool.

- linuxDownloadLink: System.String
  - Download link for the Linux binary of RVCDT.
- windowsDownloadLink: System.String
  - Download link for the Windows binary of RVCDT.
- macOsDownloadLink: System.String
  - Download link for the MacOS binary of RVCDT.
