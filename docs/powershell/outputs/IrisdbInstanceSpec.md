### IrisdbInstanceSpec
IRIS DB instance install/version details.

- instanceVersion: System.String
  - The IRIS DB software version.
- installDir: System.String
  - The IRIS installation directory path.
- dataDir: System.String
  - The primary data directory path.
- wijDir: System.String
  - The Write Image Journal (WIJ) directory path.
- journalDir: System.String
  - The journal directory path.
- altJournalDir: System.String
  - The alternate journal directory path.
