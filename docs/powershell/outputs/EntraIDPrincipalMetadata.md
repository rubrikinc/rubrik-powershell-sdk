### EntraIDPrincipalMetadata
EntraIDPrincipalMetadata represents EntraID-specific metadata.

- apiPermissions: list of PrincipalAPIPermissionGrants
  - List of API permissions granted to this principal.
- owner: System.String
  - Owner of the principal.
- appId: System.String
  - Application ID of the principal.
- appName: System.String
  - Application name of the principal.
- entraIdPrincipalSpecificMetadata: PrincipalMetadata
  - Represents Entra ID principal metadata.
