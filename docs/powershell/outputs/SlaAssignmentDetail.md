### SlaAssignmentDetail
SLA is a more specific effective SLA, separating "unprotected" into
"no_assignment" and "do_not_protect".

- noAssignment: System.Boolean
  - No SLA assigned to this object.
- doNotProtect: System.Boolean
  - Object not explicitly protected.
- slaId: System.String
  - ID of the SLA assigned to this object.
