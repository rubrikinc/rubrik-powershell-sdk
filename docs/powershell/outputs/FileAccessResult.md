### FileAccessResult
Activity summary for a single accessed file.

- nativePath: System.String
  - File path formatted for the OS or share type.
- filename: System.String
  - Name of the file.
- directory: System.String
  - Directory containing the file.
- numAccesses: System.Int32
  - Number of times the file was accessed.
- accessType: ActivityAccessType
  - Type of activity performed on the file.
