### RecoveryPlanCdmCluster
Identifying details for a CDM cluster used as a recovery plan location.

- id: System.String
  - Identifier of the CDM cluster.
- name: System.String
  - Name of the CDM cluster.
- status: ClusterStatus
  - Connection status of the CDM cluster.
- version: System.String
  - Software version running on the CDM cluster.
