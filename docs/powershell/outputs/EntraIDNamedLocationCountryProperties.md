### EntraIDNamedLocationCountryProperties
EntraIDNamedLocationCountryProperties contains properties specific to
Entra ID named location of country type.

- countriesAndRegions: list of System.Strings
  - List of countries and/or regions in two-letter format specified by ISO 3166-2.
- includeUnknownCountriesAndRegions: System.Boolean
  - Indicates whether unknown countries and regions are included in the named location.
- countryLookupMethod: EntraIDCountryLookupMethod
  - The method used to determine the country for sign-in.
