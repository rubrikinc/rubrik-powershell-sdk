### O365CalendarFolder
A calendar folder.

- name: System.String
  - The display name of the calendar folder.
- snapshotId: System.String
  - The snapshot ID of this version of the calendar folder.
- snapshotTime: DateTime
  - The snapshot time of this version of the event.
- isCalendarGroup: System.Boolean
  - Indicates if this folder represents a Calendar Group.
- hierarchyType: ExchangeItemHierarchyType
  - Type of hierarchy for the specified calendar folder.
- id: System.String
  - The ID of the Microsoft 365 Exchange object.
- parentFolderId: System.String
  - The parent folder ID of the object (ROOT indicates root folder).
