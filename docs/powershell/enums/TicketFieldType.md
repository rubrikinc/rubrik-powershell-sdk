### TicketFieldType
Unified field type enum for dynamic ticket field handling across all platforms.

- FIELD_TYPE_STRING - Single-line text input field.
- FIELD_TYPE_NUMBER - Numeric input field.
- FIELD_TYPE_OPTION - Single select dropdown field.
- FIELD_TYPE_MULTI_OPTION - Multi-select dropdown field.
- FIELD_TYPE_ARRAY - Array of strings field (e.g., labels, tags).
- FIELD_TYPE_USER - User picker field for assigning users.
- FIELD_TYPE_DATE - Date picker field.
- FIELD_TYPE_DATETIME - Date and time picker field.
- FIELD_TYPE_BOOLEAN - Boolean checkbox/toggle field.
- FIELD_TYPE_TEXT_AREA - Multi-line text area field.
