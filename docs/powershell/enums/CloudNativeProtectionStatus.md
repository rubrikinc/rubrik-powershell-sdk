### CloudNativeProtectionStatus
Protection status of a cloud native object.

- PROTECTION_STATUS_UNSPECIFIED - Unspecified protection status.
- PROTECTION_STATUS_UNPROTECTED - Unprotected.
- PROTECTION_STATUS_PARTIALLY_PROTECTED - Partially protected.
- PROTECTION_STATUS_PROTECTED - Protected.
- PROTECTION_STATUS_PROTECTED_WITH_WARNINGS - Protected, but one or more actionable warnings apply
(e.g. missing exocompute, missing backup location, non-compliant SLA).
