### TagConditionOperator
IAM Condition string operator, e.g. StringEquals or StringLike.

- TAG_CONDITION_OPERATOR_UNSPECIFIED - This operator is unspecified and is rejected during validation.
- TAG_CONDITION_OPERATOR_STRING_EQUALS - Maps to the IAM StringEquals condition operator.
- TAG_CONDITION_OPERATOR_STRING_NOT_EQUALS - Maps to the IAM StringNotEquals condition operator.
- TAG_CONDITION_OPERATOR_STRING_LIKE - Maps to the IAM StringLike condition operator.
- TAG_CONDITION_OPERATOR_STRING_NOT_LIKE - Maps to the IAM StringNotLike condition operator.
- TAG_CONDITION_OPERATOR_NULL - Maps to the IAM Null condition operator.
