### PropertyFilterField
Fields available for filtering resource properties.

- AWS_VPC_STATUS - Filter by AWS VPC status.
- NATIVE_NAME_OR_URI - Filter by native name or native URI.
- AWS_LOAD_BALANCER_STATUS - Filter by ELB status.
- AWS_LOAD_BALANCER_TYPE - Filter by ELB type.
- AWS_LOAD_BALANCER_VPC - Filter by ELB attached VPC.
