### NetworkAdapterType
Network adapter type for virtual machines.

- E1000 - Intel E1000 network adapter.
- E1000E - Intel E1000E network adapter.
- PCNET32 - PCNet32 network adapter.
- VMXNET - VMware VMXNET network adapter.
- VMXNET2 - VMware VMXNET2 network adapter.
- VMXNET3 - VMware VMXNET3 network adapter.
