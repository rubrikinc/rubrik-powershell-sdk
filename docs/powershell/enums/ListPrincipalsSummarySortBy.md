### ListPrincipalsSummarySortBy
Field on which to sort the principal summaries.

- RISK_LEVEL - Sort based on risk level.
- RISK_SENSITIVE_FILES - Sort based on risk-sensitive files.
- RISK_SENSITIVE_HITS - Sort based on risk-sensitive hits.
- TOTAL_SENSITIVE_HITS - Sort based on total sensitive hits.
- TOTAL_SENSITIVE_FILES - Sort based on total sensitive files.
- SID - Sort based on SID.
- TOTAL_SENSITIVE_OBJECTS - Sort based on the object count.
- RISK_TOTAL_SENSITIVE_HITS - Sort based on risk and total sensitive hits.
- NAME - Sort based on name.
- VIOLATIONS - Sort based on violations.
- ORIGIN - Sort based on origin.
- IDENTITY_PROVIDER_TYPE - Sort based on type of identity provider.
- PRINCIPAL_TYPE - Sort based on principal type.
- UNIQUE_IDENTIFIER - Sort based on unique identifier.
- TITLE - Sort based on title.
- ENTITY_NAME - Sort based on entity name.
- CREATION_TIME - Sort based on native creation time.
