### M365DashboardOperationMode
Dashboard operation mode for a workload type of an org.

- DAY_TO_DAY_MODE - Day to day mode.
- ONBOARDING_MODE - Onboarding mode.
- PRIORITIZED_ONBOARDING - Prioritized onboarding mode, in which a selected subset of objects is
onboarded ahead of the rest.
- BACKFILL_ONBOARDING - Backfill onboarding mode, in which the objects deferred by prioritized
onboarding are onboarded.
