### RestoreDataType
Specifies the type of data to be restored.

- SALESFORCE_RECORD - Specifies that the data to be restored is Salesforce records.
- SALESFORCE_OBJECT - Specifies that the data to be restored is Salesforce objects.
- SALESFORCE_METADATA - Specifies that the data to be restored is Salesforce metadata.
- SALESFORCE_FIELD - Specifies that the data to be restored is Salesforce fields.
