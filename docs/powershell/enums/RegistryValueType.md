### RegistryValueType
RegistryValueType enumerates the Windows registry value types exposed as
hunt filters.

- VALUE_TYPE_REG_SZ - REG_SZ: a null-terminated string.
- VALUE_TYPE_REG_EXPAND_SZ - REG_EXPAND_SZ: a null-terminated string containing unexpanded environment-variable references.
- VALUE_TYPE_REG_BINARY - REG_BINARY: raw binary data.
- VALUE_TYPE_REG_DWORD - REG_DWORD: a 32-bit number.
- VALUE_TYPE_REG_QWORD - REG_QWORD: a 64-bit number.
- VALUE_TYPE_REG_MULTI_SZ - REG_MULTI_SZ: an array of null-terminated strings.
- VALUE_TYPE_REG_NONE - REG_NONE: no defined value type.
