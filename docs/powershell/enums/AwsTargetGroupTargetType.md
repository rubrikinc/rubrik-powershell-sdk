### AwsTargetGroupTargetType
Target type of an AWS Target Group.

- AWS_TG_TARGET_TYPE_INSTANCE - Targets are EC2 instances.
- AWS_TG_TARGET_TYPE_IP - Targets are IP addresses.
- AWS_TG_TARGET_TYPE_LAMBDA - Targets are Lambda functions.
- AWS_TG_TARGET_TYPE_ALB - Targets are Application Load Balancers.
