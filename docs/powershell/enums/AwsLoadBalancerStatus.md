### AwsLoadBalancerStatus
Status of an AWS Load Balancer.

- AWS_LB_STATUS_ACTIVE - Load balancer is active and serving traffic.
- AWS_LB_STATUS_PROVISIONING - Load balancer is being provisioned.
- AWS_LB_STATUS_FAILED - Load balancer has failed.
- AWS_LB_STATUS_ACTIVE_IMPAIRED - Load balancer is active but impaired.
