### AzureOauthResource
The resource for which OAuth access is requested.

- AZURE_RESOURCE_MANAGER - Azure Resource Manager.
- AZURE_SQL - Azure SQL resources.
- AZURE_OSS_RDBMS - Represents the Azure Database for PostgreSQL / MySQL (OSS RDBMS) resource.
- AZURE_COSMOS_NOSQL - Represents the Azure Cosmos DB for NoSQL data plane resource.
