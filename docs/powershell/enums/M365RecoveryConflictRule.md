### M365RecoveryConflictRule
How M365 Access Recovery handles data that already exists in the recovered
principal's M365 workloads.

- M365_RECOVERY_CONFLICT_RULE_UNSPECIFIED - The conflict rule is unspecified.
- M365_RECOVERY_CONFLICT_RULE_KEEP_EXISTING_DATA - Keep existing data; recovered content does not replace it.
- M365_RECOVERY_CONFLICT_RULE_OVERWRITE - Replace existing data with the recovered content.
