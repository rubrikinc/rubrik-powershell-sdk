### SupportCasesSortField
Field used to sort support cases.

- SORT_FIELD_UNSPECIFIED - Unspecified; defaults to CreatedDate.
- SORT_FIELD_CASE_NUMBER - Sort by case number.
- SORT_FIELD_SUBJECT - Sort by case subject.
- SORT_FIELD_STATUS - Sort by case status.
- SORT_FIELD_PRIORITY - Sort by case priority.
- SORT_FIELD_TYPE - Sort by case type.
- SORT_FIELD_CREATED_DATE - Sort by case creation date.
