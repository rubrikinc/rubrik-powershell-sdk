### ConfigResourcePropertyName
Property name for config resources.

- CONFIG_RESOURCE_PROPERTY_NAME_LOAD_BALANCER_STATE - Load balancer state.
- CONFIG_RESOURCE_PROPERTY_NAME_LOAD_BALANCER_TYPE - Load balancer type.
- CONFIG_RESOURCE_PROPERTY_NAME_VPC_ID - VPC ID.
- CONFIG_RESOURCE_PROPERTY_NAME_VPC_STATUS - VPC Status.
