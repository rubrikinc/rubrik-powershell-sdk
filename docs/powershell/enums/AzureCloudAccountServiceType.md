### AzureCloudAccountServiceType
Service type of an Azure subscription, used to differentiate BaaS and
non-BaaS onboarding flows.

- AZURE_CLOUD_ACCOUNT_SERVICE_TYPE_UNSPECIFIED - Default unspecified value. Treated as non-BaaS.
- AZURE_CLOUD_ACCOUNT_SERVICE_TYPE_NON_BAAS - Standard (non-BaaS) Azure subscription.
- AZURE_CLOUD_ACCOUNT_SERVICE_TYPE_BAAS - Backup as a Service (BaaS) Azure subscription.
