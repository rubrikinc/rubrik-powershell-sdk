### FusionComputeVrmUserType
Supported in v9.6+
User type Rubrik logs in to a FusionCompute VRM with.

- FUSION_COMPUTE_VRM_USER_TYPE_DOMAIN_USER - A domain user account.
- FUSION_COMPUTE_VRM_USER_TYPE_INTERCONNECTION_USER - An interface interconnection user account.
- FUSION_COMPUTE_VRM_USER_TYPE_LOCAL_USER - A user account local to the VRM. The default.
