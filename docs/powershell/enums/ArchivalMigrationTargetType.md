### ArchivalMigrationTargetType
Enum for archival migration target location types.

- ARCHIVAL_MIGRATION_TARGET_S3_COMPATIBLE - S3 compatible target type.
- ARCHIVAL_MIGRATION_TARGET_RCV_AWS - Rubrik Cloud Vault on AWS target type.
- ARCHIVAL_MIGRATION_TARGET_RCV_AZURE - Rubrik Cloud Vault on Azure target type.
