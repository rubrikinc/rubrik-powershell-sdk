### AwsEksComputeType
Compute type of an AWS EKS cluster: managed node groups, Fargate profiles,
or a mix of both.

- AWS_EKS_COMPUTE_TYPE_MANAGED_NODE_GROUP - Cluster uses only managed node groups.
- AWS_EKS_COMPUTE_TYPE_FARGATE - Cluster uses only Fargate profiles.
- AWS_EKS_COMPUTE_TYPE_BOTH - Cluster uses both managed node groups and Fargate profiles.
- AWS_EKS_COMPUTE_TYPE_SELF_MANAGED - Cluster uses self-managed EC2 nodes.
