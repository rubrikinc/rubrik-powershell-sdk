### AwsEcsCapacityProviderType
Capacity mode an AWS ECS cluster can run its tasks on.

- AWS_ECS_CAPACITY_PROVIDER_TYPE_FARGATE - Fargate on-demand capacity.
- AWS_ECS_CAPACITY_PROVIDER_TYPE_FARGATE_SPOT - Fargate Spot capacity.
- AWS_ECS_CAPACITY_PROVIDER_TYPE_EC2_AUTO_SCALING - EC2 capacity backed by an Auto Scaling group capacity provider.
- AWS_ECS_CAPACITY_PROVIDER_TYPE_SELF_MANAGED - Self-managed EC2 capacity: registered container instances or an
ECS Managed Instances capacity provider.
