### AzureCosmosNosqlThroughputMode
How throughput is provisioned for an Azure Cosmos NoSQL resource.

- AZURE_COSMOS_NOSQL_THROUGHPUT_MODE_UNSPECIFIED - Throughput mode has not been determined.
- AZURE_COSMOS_NOSQL_THROUGHPUT_MODE_MANUAL - Fixed request units per second.
- AZURE_COSMOS_NOSQL_THROUGHPUT_MODE_AUTOSCALE - Request units per second scale up to a configured ceiling.
- AZURE_COSMOS_NOSQL_THROUGHPUT_MODE_SERVERLESS - Account-level serverless capability; no throughput settings exist.
