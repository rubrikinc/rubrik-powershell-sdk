### RcvResourceCreationReadiness
Indicates the provisioning state of the cloud resources for a Rubrik Cloud
Vault (RCV) archival target.

- RCV_RESOURCE_CREATION_READINESS_UNSPECIFIED - The readiness of the cloud resources has not been determined.
- RCV_RESOURCE_CREATION_READY - The cloud resources are provisioned and the archival target is ready for use.
- RCV_RESOURCE_CREATION_IN_PROGRESS - The cloud resources are being provisioned.
- RCV_RESOURCE_CREATION_FAILED - The cloud resources could not be provisioned or validated.
