### MaskingOverrideInput
Custom masking technique overrides for specific object fields.

- workloadId: System.String
  - Object ID (e.g., workload identifier).
- fieldOverrides: list of FieldOverrideInputs
  - List of field overrides for this object.
- schemaName: System.String
  - Name of the schema or the appItemTypeToken value of the object (e.g. Accounts, Contact).
