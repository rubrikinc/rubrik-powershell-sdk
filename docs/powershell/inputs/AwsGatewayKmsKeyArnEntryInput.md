### AwsGatewayKmsKeyArnEntryInput
A manually-onboarded application account's customer-provided gateway KMS key ARN.

- applicationCloudAccountId: System.String
  - Rubrik ID of the application cloud account this gateway KMS key ARN is for.
- gatewayKmsKeyArn: System.String
  - Customer-provided multi-region gateway KMS key ARN for this account.
