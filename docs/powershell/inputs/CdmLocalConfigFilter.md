### CdmLocalConfigFilter
Filters for the CDM local configuration parameter list.

- searchTerm: System.String
  - Optional substring filter on parameter name.
- states: list of CdmConfigParamStates
  - Optional filter restricting results to these parameter states.
- nodes: list of System.Strings
  - Optional filter restricting results to these node identifiers.
- namespaces: list of System.Strings
  - Optional filter restricting results to these namespaces.
