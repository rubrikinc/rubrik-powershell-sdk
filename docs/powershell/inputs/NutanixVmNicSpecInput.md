### NutanixVmNicSpecInput
Network configuration for Nutanix virtual machine recovery.

- key: System.String
  - Device key for Nutanix virtual machine NIC identification (e.g., "4000",
"4001").
- networkName: System.String
  - Name of the Nutanix network.
- networkUuid: System.String
  - UUID of the Nutanix network.
