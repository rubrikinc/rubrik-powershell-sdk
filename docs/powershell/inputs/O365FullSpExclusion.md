### O365FullSpExclusion
SharePoint object excluded from protection. Used as GraphQL input
`O365FullSpExclusion` and output `FullSpObjectExclusion`.

- fid: System.String
  - The fid of the SharePoint object.
- name: System.String
  - The name of the SharePoint object.
- url: System.String
  - The URL of the SharePoint object.
- objectType: SharePointDescendantType
  - The object type.
