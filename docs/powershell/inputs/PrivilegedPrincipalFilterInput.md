### PrivilegedPrincipalFilterInput
Filter to be applied when retrieving privileged principal summaries.

- timelineDate: System.String
  - Filter for the requested date for privileged principals.
- principalTypes: list of PrincipalRiskySummaryPrincipalTypes
  - Filter for principal types.
- idpTypes: list of IdpTypes
  - Filter for Idp types.
