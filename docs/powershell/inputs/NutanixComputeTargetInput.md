### NutanixComputeTargetInput
Nutanix compute target.

- clusterId: System.String
  - ID of the target Nutanix cluster.
- clusterName: System.String
  - Name of the target Nutanix cluster.
- clusterHostname: System.String
  - Hostname of the target cluster.
- prismCentral: System.String
  - Prism Central information.
