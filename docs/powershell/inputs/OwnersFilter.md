### OwnersFilter
Filter to be applied when retrieving potential owner principals.

- searchTerm: System.String
  - Search string to match owner name.
- idpTypesFilter: list of IdpTypes
  - Filter by identity provider types.
- principalTypes: list of PrincipalRiskySummaryPrincipalTypes
  - Filter by principal types.
- timelineDate: System.String
  - Timeline date for the query.
