### PrioritizedOnboardingSpec
Prioritized onboarding configuration for the M365 setup flow.

- operationMode: O365SetupOperationMode
  - Operation mode for the setup flow.
- prioritizedOnboardingDays: System.Int32
  - Number of days for the prioritized onboarding window.
Only applicable when operation_mode is O365_SETUP_OPERATION_MODE_PRIORITIZED_ONBOARDING.
