### DriveRestoreConfig
Represents the OneDrive contents to be restored.

- filesToRestore: list of FileInfos
  - The files to restore.
- foldersToRestore: list of FolderInfos
  - The folders to restore.
- restoreFolderPath: System.String
  - Path within the destination to restore to.
- shouldRestoreFileVersions: System.Boolean
  - Whether to restore all file versions.
