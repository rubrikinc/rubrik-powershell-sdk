### VsphereVmVolumeSpecInput
VSphere virtual machine volume specification.

- key: System.String
  - Device key for vsphere volume identification.
- dataStoreId: System.String
  - Datastore ID for the volume.
- sizeGbs: System.Single
  - Size of the volume in GB.
- dataStoreCdmId: System.String
  - CDM ID of the datastore.
- datastoreClusterId: System.String
  - Datastore cluster ID if using datastore cluster.
- label: System.String
  - Label for the volume.
