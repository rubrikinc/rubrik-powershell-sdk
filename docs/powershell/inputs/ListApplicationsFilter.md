### ListApplicationsFilter
Filter criteria for filtering cloud native applications.

- cloudNativeAccountIds: list of System.Strings
  - Filter by cloud account ID.
- refreshStatus: list of CloudNativeApplicationRefreshStatuss
  - Filter on refresh status.
- regionIds: list of CloudRegionInputs
  - Filter by region ID.
- protectionStatus: list of CloudNativeProtectionStatuss
  - Filter by protection status.
- cloudTypes: list of CloudServiceProviders
  - Filter by cloud type.
- applicationName: System.String
  - Filter by application name.
