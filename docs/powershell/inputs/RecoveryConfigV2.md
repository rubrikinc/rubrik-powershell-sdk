### RecoveryConfigV2
Recovery configuration.

- dataTransferType: DataTransferType
  - Data transfer type.
- preferredLocationType: SnapshotLocationType
  - Preferred location type for snapshots during OAR workflows.
- ignoreNetworkReconfigureError: System.Boolean
  - Whether a scheduled Disaster Recovery test ignores network reconfiguration errors. Setting this to true means the
test recovery ignores network reconfiguration errors.
