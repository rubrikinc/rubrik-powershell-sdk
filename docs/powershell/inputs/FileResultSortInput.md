### FileResultSortInput
Sort configuration applied when listing or browsing file results.

- sortBy: FileResultSortBy
  - Attribute to sort the file results by.
- sortOrder: SortOrder
  - Direction to sort the file results in.
- analyzerGroupId: System.String
  - Data category to sort hit counts by, when sorting by a category.
- dataTypeId: System.String
  - ID of data type to sort file results.
